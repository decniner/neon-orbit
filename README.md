# NEON ORBIT — Mobile Flight

A touch-first, full-screen space-shooter edition for Android and iOS browsers.

## Play

https://decniner.github.io/neon-orbit/

## Update the published game

The `site/` directory contains the mobile edition synced from [`decniner/Games/mobile`](https://github.com/decniner/Games/tree/main/mobile). Push changes to `site/` on `main` to publish them to GitHub Pages.
